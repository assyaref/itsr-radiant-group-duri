## 3. Credential handling
- Passwords are 24+ random characters, generated by `crypto.randomBytes`. They were **never printed** to any terminal, log, report or chat.
- They are stored **only** in `%USERPROFILE%\.itsr-staging\test-accounts.json`.
  - That file is outside the repository, and its NTFS ACL is restricted to the current Windows user (inheritance removed).
  - `.gitignore` also blocks `*test-accounts*.json` as a second line of defence.
- `STGEMP01`'s password was **rotated** during the admin password-reset test. The credentials file holds the current value.
- To hand these accounts to a human tester: read the file locally and share the password over a secure channel. Rotate it afterwards with `admin-users` → `reset_password`.
